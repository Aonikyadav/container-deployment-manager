# Container Deployment Manager

A sophisticated, multi-tenant container orchestration platform for blue-green deployments with built-in authentication and security.

## Features
- **Blue-Green Deployment**: Zero-downtime updates for your containerized applications.
- **Multi-Tenant Architecture**: Individual user Dashboards and Profile management.
- **Secure Authentication**: JWT-based session management and Bcrypt password hashing.
- **Real-time Monitoring**: System health and deployment status alerts.
- **Automated Migration**: Seamlessly adopt existing deployments into a primary administrative account.

## Tech Stack
- **Backend**: Node.js, Express.js, MongoDB (Mongoose)
- **Frontend**: React, Vite, Lucide Icons, Tailwind-inspired Vanilla CSS
- **Orchestration**: Docker Engine API
